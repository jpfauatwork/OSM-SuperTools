OSM SuperTools

A modular toolkit for the iD editor. Configure each module below, then press Save.

QuickTagging

Buttons in the editor sidebar that apply one or several tags at once. Clicking a button overwrites the value of every key it sets on the selected feature.

QuickFilters

Named filters you can toggle from the map controls (right side, funnel icon). Each highlights the currently loaded features that match its query, in a color you choose. Only features already loaded in the browser are queried — no network requests.
